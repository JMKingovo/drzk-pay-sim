道尔车场支付模拟器 —— 使用说明
==================================================

这是一个单文件客户端：不用安装、不用管理员权限，双击启动即可。
启动后会在本机开一个网页界面，浏览器自动打开；关掉黑色窗口就退出。

一、第一次启动
--------------------------------------------------
Windows
  双击「启动.cmd」。
  如果出现「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
  程序未做数字签名，这是正常提示。

macOS
  双击「启动.command」。
  如果提示「无法打开，因为无法验证开发者」：
  右键点「启动.command」→ 打开 → 打开；
  或在「终端」里执行一次：
    xattr -dr com.apple.quarantine <这个文件夹的路径>

Linux
  双击「启动.sh」，或在该目录执行 ./启动.sh

二、界面怎么用
--------------------------------------------------
1. 顶部「目标车场 IP」填车场服务器地址，点「连接车场」。
2. 能连上的话会自动探测出车场编号、MQTT 凭证和岗亭。
   探不到（没有 SSH 权限）就在顶部「车场参数」里手填，保存后重连。
3. 左边是出口收费弹窗：车场那边有车在出口扫码待缴费时，这里会实时显示车牌和金额，
   点「立即代缴开闸放行」就会注入一笔支付并联动开闸。
4. 右边可以手工输车牌查费、做场内预缴（不抬杆）。
5. 底部是支付记录，会一直保存，关掉重开也在。

三、最重要的一条
--------------------------------------------------
「报文发出去了」不等于「车场收到了」。

每笔支付下面都有一行车场回执：
  车场已收到并生成出场流水   → 正常，车场有出场记录
  车场已收到，但未生成出场流水 → 钱进了车场，但那一刻通道上没这台车，所以没有出场流水
  车场没有收到这笔缴费      → 车场完全没收到，车场里不会有任何记录
  无法校验                  → 连不上车场数据库，不知道收没收到，不要当成成功

看到「车场没有收到」，先看提示里的原因：
  · 写着「车场未开启云端」→ 这台车场没开云端，谁都注入不进去，需要车场后台打开
  · 写着「车场编号已经变成 X」→ 车场被重新初始化了，重新点一次「连接车场」

四、配置和数据存在哪
--------------------------------------------------
Windows   C:\Users\<你的用户名>\.drzk-pay-sim.json
macOS     ~/.drzk-pay-sim.json
Linux     ~/.drzk-pay-sim.json

这个文件里有车场 MQTT 密码，不要发给别人、不要提交到 git。
支付记录在同目录的 .drzk-pay-sim-history.json。

五、常见问题
--------------------------------------------------
· 端口被占用：程序会自动改用下一个端口，窗口里会打印实际地址。
· 只能本机访问：默认只监听 127.0.0.1，同网段其他人打不开你的页面。
  确实需要别人访问时加参数：启动.cmd / 启动.command 后加 --host 0.0.0.0
· 想看更多日志：窗口里会实时打印每笔支付的完整报文和车场回执。
