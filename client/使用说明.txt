道尔车场支付模拟器 使用说明
==================================================

本程序为单文件客户端，无需安装、无需管理员权限。启动后在本机开启一个
Web 控制台，浏览器自动打开；关闭命令行窗口即退出程序。

一、启动
--------------------------------------------------
Windows
  双击「启动.cmd」。
  程序未做数字签名，首次启动时 Windows 会提示「已保护你的电脑」，
  点击「更多信息」→「仍要运行」即可。

macOS
  双击「启动.command」。
  若提示「无法打开，因为无法验证开发者」，采用以下任一方式：
    · 右键点击「启动.command」→「打开」→「打开」
    · 在终端执行一次：xattr -dr com.apple.quarantine <本目录路径>

Linux
  在本目录执行 ./启动.sh，或双击「启动.sh」。

二、界面操作
--------------------------------------------------
1. 在顶部「目标车场 IP」填入车场服务器地址，点击「连接车场」。
2. 连接成功后，程序会自动探测车场编号、MQTT 凭证与岗亭信息。
   若当前账号无 SSH 权限导致探测失败，可在顶部「车场参数」中手工填写后重新连接。
3. 左侧为出口收费弹窗区域。车场出口有待缴费车辆时，此处实时显示车牌与金额；
   点击「立即代缴开闸放行」将注入一笔支付并联动开闸。
4. 右侧支持按车牌手工查费与场内预缴（场内预缴不抬杆）。
5. 底部为支付记录，持久化保存，重启程序后仍然保留。

三、支付回执（重要）
--------------------------------------------------
报文成功发出，不等于车场已经收到。每笔支付下方均显示车场回执：

  车场已收到并生成出场流水      车场入账，且生成了正式出场记录
  车场已收到，但未生成出场流水  车场入账，但缴费时通道内无该车出场事件
  车场没有收到这笔缴费          车场未入账，不会产生任何记录
  无法校验                      无法连接车场数据库，不能视为成功

出现「车场没有收到这笔缴费」时，请先阅读提示中的原因：
  · 提示「车场未开启云端」：该车场未开启云端订阅，任何客户端都无法注入，
    需在车场后台开启「上传数据云端」与「云端总开关」。
  · 提示「车场编号已经变成 X」：车场已被重新初始化，请重新点击「连接车场」。

四、配置与数据
--------------------------------------------------
Windows   C:\Users\<用户名>\.drzk-pay-sim.json
macOS     ~/.drzk-pay-sim.json
Linux     ~/.drzk-pay-sim.json

该文件包含车场 MQTT 密码，请勿转发或提交至版本库。
支付记录位于同目录下的 .drzk-pay-sim-history.json。

五、常见问题
--------------------------------------------------
· 端口被占用：程序自动改用下一个可用端口，实际访问地址在窗口中打印。
· 仅限本机访问：默认监听 127.0.0.1，同网段其他主机无法访问。
  如需对外开放，在启动命令后追加 --host 0.0.0.0。
· 需要查看详细过程：窗口实时输出每笔支付的完整报文与车场回执。
